# LOGBOOK
In here i write down stuff that i learnt in the process of this project, for future reference

## HTML
- <br> is a line break/enter, i used it to make a container not 0px in height when floating two divs

## CSS
- with `backdrop-filter: blur()` you can add blur behind a shape or object
- With `float` you can work with columns
- `text-decoration: none` removed the line under links (used on the buttons)
- use `:hover` on a style to make it update properties on hovering the object
- use `transition: width 2s, height 2s` to add animations to `:hover` styles or something like that 
- `transform: translate()` applies to the object your using it on (so a translation of -50% of a div means the div moves half its size)
